# 渠道数据分析平台v1.3

## 📖 项目简介

渠道数据分析平台 (ChannelMaster) 是专为政企生态合作部设计的数据分析工具。平台集成代理商全生命周期数据，通过智能化的前端数据处理和可视化的图表展示，帮助管理人员快速洞察业务现状，驱动科学决策。

本项目采用纯前端架构（HTML + JS），配合轻量级 Python 脚本辅助，无需复杂的后端部署即可直接运行。

## 🚀 主要功能模块

### 1. 运营概览门户 (`主页.html`)
- **功能入口**：作为系统主页，提供各个子系统的快捷入口。
- **技能导航**：展示“月租分析”、“流失分析”、“收入分析”、“集群分析”等核心技能卡片。
- **全局搜索**：支持关键词搜索功能模块（前端模拟）。

### 2. 代理商签约情况分析 (`代理商签约情况分析.html`)
**核心功能：月租大盘分析与代理商画像**
- **数据处理**：支持上传月租数据 Excel，前端自动解析。
- **全网概览**：实时计算全网新签、流失、净签月租总额。
- **趋势分析**：提供月度营收趋势的折线图/柱状图切换。
- **排名榜单**：自动生成代理商、客户、营销单元维度的 Top 20 排名（新签/流失/净签）。
- **详情查询**：支持搜索特定代理商，展示其专属分析卡片（含同星级排名、客户维度分析等）。
- **报告导出**：支持将代理商分析结果一键导出为 PDF 报告。
- **异常处理**：内置异常值检测模块，支持手动剔除异常数据。

### 3. 流失分析 (`流失分析.html`)
**核心功能：流失原因自动归因**
- **智能判定**：系统自动根据业务规则将流失记录归类为：
  - 🟢 **渠道间迁移**：业务从一个代理商转移到另一个代理商。
  - 🔵 **渠转直销**：业务转为联通直销。
  - 🔴 **纯流失**：彻底流失出网。
- **可视化看板**：展示各类流失金额占比、流失严重的营销单元与代理商排名。
- **明细导出**：支持导出包含判定结果的 Excel 明细表。

### 4. 收入可视化分析 (`代理商收入可视化分析.html`)
**核心功能：多维度收入构成分析**
- **多维筛选**：支持按账期、产品类型筛选数据。
- **图表展示**：
  - 产品类型收入分布（饼图/柱图）。
  - 收入趋势分析。
- **个案查询**：查询特定代理商或客户的月度业绩表现。

### 5. 辅助工具
- **使用手册 (`user_manual.html`)**：详细的平台操作指南与常见问题解答。
- **数据处理脚本 (`agent_data_system.py`)**：基于 Python (Pandas + SQLite) 的后端数据处理工具，用于批量处理数据并生成静态 HTML 报告 (`agent_analysis_report.html`)。

## 🛠️ 技术栈

本项目主要基于现代前端技术栈构建，依赖 CDN 资源，无需本地构建过程。

- **核心框架**: HTML5, Vue 3 (仅主页), Tailwind CSS (样式)
- **图表库**: 
  - Chart.js (签约/流失分析)
  - ECharts (收入分析)
- **数据处理**: 
  - SheetJS (xlsx) - 前端 Excel 解析
  - Python (Pandas, SQLite3) - 后端批处理
- **工具库**: 
  - html2pdf.js - PDF 导出
  - Lucide Icons - 图标库

## 💻 使用说明

### 方式一：直接运行 (推荐)
1. 直接在浏览器中打开 `主页.html`。
2. 根据页面指引，点击相应卡片进入子功能模块。
3. 在各模块中上传符合模板要求的 Excel 数据文件即可进行分析。

### 方式二：Python 脚本处理
如果您需要处理大量历史数据或生成综合报告，可以使用 Python 脚本：

1. 确保已安装 Python 3 及依赖库：
   ```bash
   pip install pandas openpyxl
   ```
2. 运行脚本初始化数据库：
   ```bash
   python agent_data_system.py init
   ```
3. 导入数据（示例）：
   ```bash
   python agent_data_system.py import_signing data/signing_data.xlsx
   python agent_data_system.py import_income data/income_data.xlsx
   ```
4. 生成报告：
   ```bash
   python agent_data_system.py report
   ```
   运行后将生成 `agent_analysis_report.html`。

## 📊 数据格式要求

上传的 Excel 文件通常需要包含以下关键字段（具体参考 `user_manual.html`）：
- **月份/账期** (YYYYMM 或 YYYY-MM)
- **代理商名称 / 渠道名称**
- **客户名称**
- **产品分类 / 产品类型**
- **金额 / 万元** (收入或月租)
- **营销单元**
